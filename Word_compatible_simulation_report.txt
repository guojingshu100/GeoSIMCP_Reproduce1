（1）S1 场景

当前项目中尚未完成 S1 的正式验证实验，因此暂无可报告的覆盖率、区间得分或条件覆盖结果。

按照冻结的数据生成机制，S1 的真实均值和尺度分别为：

μ = 2x₁

σ = h(x₁) = 0.6 + 1.4 / (1 + exp(−1.2x₁))

S1 中，条件均值和噪声尺度由同一个变量 x₁ 驱动，因此它属于均值与尺度驱动一致的异方差场景。后续如开展验证，应继续使用冻结的点预测器、原始特征和预先确定的尺度学习方案。

（2）S2 场景

S2 的真实数据生成机制为：

μ = 2x₁

σ = h(x₂) = 0.6 + 1.4 / (1 + exp(−1.2x₂))

S2 中，均值由 x₁ 决定，噪声尺度由 x₂ 决定。由于均值驱动变量和尺度驱动变量相互分离，普通 CP 容易出现不同 x₂ 区间之间的条件覆盖不平衡。

D6R 清洁 HGBR 复现实验

在 n_cal = 100 时：

CP 的平均覆盖率为 0.90740，平均区间得分为 6.149869，x₂ 五分位覆盖率范围为 0.17175。

HGBR-M1-NCP 的平均覆盖率为 0.90750，平均区间得分为 6.345020，x₂ 五分位覆盖率范围为 0.06600。

Oracle-NCP 的平均区间得分为 5.701275。

HGBR-M1-NCP 明显降低了 x₂ 五分位覆盖率范围，说明它改善了条件覆盖平衡；但其平均区间得分比 CP 高 0.195151，约高 3.256982%。因此，HGBR 学习尺度能够改善条件校准，但尚未改善区间效率。

D7A KNN 与 HGBR 对比实验

D7A 使用固定的 KNN 尺度学习器：

StandardScaler() → KNeighborsRegressor(n_neighbors = 20, weights = distance)

在 n_cal = 100 时：

CP 的平均覆盖率为 0.90625，平均区间得分为 6.197132，x₂ 五分位覆盖率范围为 0.19225。

HGBR-NCP 的平均覆盖率为 0.88965，平均区间得分为 6.286031，x₂ 五分位覆盖率范围为 0.07325。

KNN-NCP 的平均覆盖率为 0.90485，平均区间得分为 6.073895，x₂ 五分位覆盖率范围为 0.10225。

Oracle-NCP 的平均覆盖率为 0.89720，平均区间得分为 5.764530，x₂ 五分位覆盖率范围为 0.05400。

KNN-NCP 相对于 CP 的平均区间得分降低 0.123237，约降低 1.975069%；相对于 HGBR-NCP 的平均区间得分降低 0.212136，约降低 3.368528%。KNN 的平均覆盖率仍处于可接受范围，并且 x₂ 五分位覆盖率范围低于 CP。

因此，D7A 的四项预设判定条件全部通过，KNN 在 S2 中被判定为 CONFIRMED。

D7C 尺度可学习性筛查

D7C 仅使用 S2 的 200 个授权 scale_fit 样本进行五折交叉验证和 OOF 评估。

S2 中，常数尺度基线的 OOF pinball loss 为 0.337545，KNN 的 OOF pinball loss 为 0.329549，相对改善为 2.368802%。平均配对改善为 0.007996，OOF 预测尺度变异系数为 0.222374，与真实 σ 的 Spearman 相关系数为 0.586777。

但是，固定 2000 次配对 bootstrap 得到的平均改善经验范围为：

−0.012093 至 0.027501

由于经验范围的第 2.5 百分位没有大于 0，D7C 按预注册规则将 S2 判定为：

SCALE NOT ESTABLISHED

这并不否定 S2 中存在正向平均信号，但说明现有 200 个 scale_fit 样本不足以将该信号确认成稳定的部署前判定依据。

（3）S3 场景

当前项目中尚未完成 S3 的正式验证实验，因此暂无可报告的覆盖率、区间得分或条件覆盖结果。

按照冻结的数据生成机制，S3 的真实均值和尺度为：

μ = 2x₁ + 1.5g_true

σ = h(g_true) = 0.6 + 1.4 / (1 + exp(−1.2g_true))

g_true = sin(2πsₓ) + cos(2πsᵧ)

g_proxy = g_true + 0.35η

S3 的均值和尺度都受到空间驱动变量影响，同时观测到的是带噪声的代理变量。由于 S3 尚未完成预注册验证，当前不应根据已有 S2 或 S4 结果推断 KNN 在 S3 上的表现。

（4）S4 场景

S4 是同方差负控制场景，其真实数据生成机制为：

μ = 2x₁

σ = 1.3

S4 不存在真实的特征依赖尺度结构，因此理想的尺度学习器不应制造明显的虚假异质性。

D7B 使用固定的 KNN 尺度学习器进行负控制检验。

CP 的平均覆盖率为 0.89555，平均区间得分为 5.688901，平均区间宽度为 4.514512，预测尺度五分位覆盖率范围为 0.04550。

KNN-NCP 的平均覆盖率为 0.89335，平均区间得分为 5.870707，平均区间宽度为 4.603750，预测尺度五分位覆盖率范围为 0.14900。

Oracle-NCP 的平均覆盖率为 0.89555，平均区间得分为 5.688901，平均区间宽度为 4.514512。

由于 σ_true = 1.3 为常数，Oracle-NCP 与 CP 的最大区间端点差异为 0，满足不变量检验。

KNN-NCP 相对于 CP 的平均区间得分增加 3.196092%，平均区间宽度增加 2.154892%。KNN 预测尺度的平均变异系数为 0.162015，说明即使真实尺度恒定，KNN 仍然产生了非零的预测尺度异质性。

KNN 的预测尺度五分位覆盖率范围为 0.14900，高于 CP 的 0.04550。因此，D7B 的负控制判定为：

NEGATIVE-CONTROL FAILURE

这表明 KNN-NCP 不应作为所有场景通用的自动尺度学习方法。

（5）综合分析

当前结果支持以下结论：

第一，S2 中的归一化保序共形方法能够明显改善条件覆盖平衡。无论使用 HGBR 还是 KNN，x₂ 五分位覆盖率范围都低于 CP。

第二，D6R 显示，原计划的 HGBR-M1-NCP 在 S2 上具有条件校准优势，但区间效率不如 CP。HGBR-M1-NCP 的平均区间得分仍高于 CP。

第三，D7A 显示，固定的 KNN 尺度学习器在 S2 上同时改善了条件覆盖和平均区间得分，四项预设确认条件全部通过。

第四，D7B 显示，KNN 在同方差 S4 场景中会产生虚假尺度异质性，并导致区间得分和区间宽度变差。因此，S2 中的 KNN 优势不能被解释为普遍适用于所有场景。

第五，D7C 的 OOF 可学习性筛查未能在预设 bootstrap 规则下确认 S2 的尺度学习信号。S2 的平均改善为正，但其 bootstrap 经验范围包含 0，因此尺度可学习性仍未建立。

第六，D7C 的尺度适用性门控判定为 B，原因是 S2 和 S4 都被判定为 SCALE NOT ESTABLISHED。当前结果不足以支持将该门控直接应用到尚未验证的场景。

第七，D6G 仍属于历史结果，其 M1 实现身份无法确认；D6H 明确使用了 KNN，但偏离了原定的 HGBR 协议。D6G 和 D6H 不应作为原计划 HGBR 方法的证据，也不应与 D6R 或 D7A 混合汇总。

当前最稳妥的科学表述是：

S2 结果表明，尺度归一化共形方法有助于改善条件覆盖平衡；KNN 在 S2 上显示出效率优势，但在同方差 S4 负控制中产生了不必要的尺度异质性。因此，KNN-NCP 只能被视为具有场景依赖性的候选方法，而不能被视为通用方法。HGBR 是原计划中的一致实现，但其区间效率仍低于 CP。S1 和 S3 尚未完成验证，现阶段不应将 S2 结果外推到这两个场景。
